# Genesis Homepage V46 — Map Build and Use Narrative

## Hero

Headline:

**一张 AI 可用的实时业务地图**

Three states:

1. **没有地图 AI 只能看见局部**
2. **Genesis 把业务世界画成地图**
3. **有了地图 AI 知道去哪 怎么走**

The three visuals must use the same base map, aligned business markers, aligned legend positions, and aligned Genesis logo positions in states 2 and 3. State 1 uses the same outer frame as the others, with only the map content darkened.

## Chapter 01 — AI Cannot See

Core message:

**AI 看不清企业自己的业务世界**

The four question marks are the actual blind spots:

- 业务结构 — 谁是谁 彼此怎么关联
- 当前事实 — 现在真正发生了什么
- 企业规则 — 什么能做 什么不能做
- 工作方式 — 这家公司通常怎么判断怎么处理

Closing:

**问题不是 AI 不聪明 而是它看不清企业自己的业务世界**

## Chapter 02 — Draw the Map

Core message:

**Genesis 把企业业务世界画成 AI 能读懂的地图**

Only explain what constitutes the map:

- 业务结构 — 对象 关系 状态
- 当前事实 — 数据 事件 证据
- 企业规则 — 规则 权限 边界
- 工作方式 — 方法 流程 能力

Output:

**AI 可用的实时业务地图**

Do not place Data Platform / LLM / Agent / Workflow architecture roles in this chapter. They distract from how the business map is constructed.

## Chapter 03 — Use the Map

Core message:

**AI 用这张地图找到目标 形成判断并完成工作**

The map enables AI to:

1. 定位 — 知道现在在哪里
2. 理解 — 知道发生了什么
3. 判断 — 知道为什么
4. 行动 — 知道下一步做什么
5. 验证 — 知道结果有没有改变

Use one concrete anonymous scenario to show the closed loop:

事实 → 上下文 → 判断 → 行动 → 验证 → 更新地图

Final value statement:

**从回答问题到完成工作**
