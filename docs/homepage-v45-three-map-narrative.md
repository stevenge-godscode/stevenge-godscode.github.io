# Homepage V45 Three-Map Narrative

## Core principle
The hero triptych is the table of contents for the whole homepage. The rest of the page should not introduce a second narrative system.

Canonical narrative:

1. **看不见** — without a business map AI faces unknowns
2. **画出来** — Genesis turns business structure facts rules and working methods into a live business map
3. **用起来** — AI uses the same map to reason navigate act verify and continue

## Chapter 01 — 看不见
Visual tone: black / dark and directly echoes the first hero map.

Headline direction:
**黑灯瞎火里 AI 面对的是一片问号**

The four unknowns must exactly match the hero legend and keep the same order:
- 业务结构?
- 当前事实?
- 企业规则?
- 工作方式?

Minimal explanations:
- 业务结构? — 不知道谁和谁有关
- 当前事实? — 不知道现在发生什么
- 企业规则? — 不知道什么能做
- 工作方式? — 不知道这家公司怎么做

Core conclusion:
**问题不是模型不聪明 而是它看不清企业自己的业务世界**

## Chapter 02 — 画出来
Visual tone: light map / Genesis blue accents and directly echoes the second hero map.

Headline direction:
**把问号变成一张实时业务地图**

The same four semantic categories are now identified and governed:
- 业务结构 — 对象 关系 状态
- 当前事实 — 数据 事件 证据
- 企业规则 — 规则 权限 边界
- 工作方式 — 方法 流程 能力

Product role should be shown as one concise responsibility line:
**现有系统提供事实 Genesis 组织业务地图 大模型负责思考 Agent 和流程负责执行**

Do not expand Ontology Context Evidence Domain Pack Trust as independent homepage sections. They are implementation details inside the map.

## Chapter 03 — 用起来
Visual tone: navigation state and directly echoes the third hero map.

Headline direction:
**有了地图 AI 才知道去哪 怎么走**

The page should show two visual layers just like the hero:
- **推理路径** — which facts rules methods and evidence support the judgment
- **行动导航** — which controlled business action should be taken next

Core value dimensions:
- 目标清楚
- 推理有据
- 行动有边界
- 结果可验证

The customer-risk scenario remains the canonical example but should be shown as a compact closed-loop route rather than six verbose cards:
`逾期18天 + 项目未验收 → 付款与验收相关 → 重点关注 → 跟进/验收确认/风险复核 → 状态回流 → 新事实`

## Section separators
Each chapter begins with a strong visual divider:
- large chapter number 01 / 02 / 03
- long horizontal rule
- short chapter label

The divider must be visible while scrolling and make the page feel like three distinct acts of one story.

## Copy discipline
- one main conclusion per screen
- headings should remain one line on desktop when practical
- no commas or periods in headings
- minimal body text
- no customer names
- all terminology and icon order should stay aligned with the hero map
